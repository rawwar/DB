# Lesson Template

Use this template for teaching a single concept. Adapt the headings as needed, but keep the progression from goal to practice to mastery.

## 1. Concept

Name the concept in one line.

Example:

`Concept: Interfaces`

## 2. Learning Goal

State what the learner should be able to do by the end.

Use this form:

`By the end, you should be able to ...`

## 3. Prerequisites

List the minimum ideas the learner needs before starting.

If a prerequisite is missing, teach that first.

## 4. Why It Matters

Explain the practical value in two or three sentences.

Do not oversell. Make the usefulness concrete.

## 5. Mental Model

Give a simple way to think about the concept.

A good mental model should help the learner predict behavior, not merely remember a definition.

## 6. Minimal Example

Show the smallest useful example.

Rules:

- Keep it small.
- Remove unrelated details.
- Explain the important parts.
- If there is code, make it runnable when possible.

## 7. Guided Practice

Ask the learner to do a small task with hints.

Good guided tasks:

- Fill in a missing line.
- Predict the output.
- Explain why something works.
- Modify one part and describe what changes.
- Find a simple bug.

## 8. Independent Practice

Give a similar task without step-by-step help.

The task should be small enough to attempt immediately but different enough to show transfer.

## 9. Common Mistakes

List two to four mistakes the learner is likely to make.

For each mistake, include how to detect it.

## 10. Mastery Check

Ask questions or assign a tiny exercise that proves readiness.

The check should verify whether the learner can:

- Explain the idea.
- Apply it.
- Debug a simple misuse.
- Recognize when to use it.

## 11. Next Step Decision

Choose one:

- Proceed to the next concept.
- Practise one more example.
- Review a prerequisite.
- Re-teach the same concept with a different example.

State the reason for the decision.
